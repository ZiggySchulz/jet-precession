# jet-precession
A repo containing code and related material to my work studying precessing AGNs.

## Files 
- animations/ : Directory containing various animations of the jets as they evolve in time  
- double_masked/ : Double masked catalogues presented to analysts
- plots/ : Plots and supplementary plots for the paper
- tests/test_symmetry_axes.py: Agreement tests between notebook and .py files
- analysis.ipynb: A working jupyter notebook used to calculate values and generate figures for the paper. Developed in collaboration with Ross Turner
- symmetry_axes.py: A cleaned Python file for readablility and import in other projects
